Welcome to the central repository for my personal portfolio. I am a developer specializing in the intersection of **Artificial Intelligence** and **Premium Frontend Engineering**. This site serves as my digital storefront, demonstrating my path toward becoming an AI Systems Architect capable of delivering robust intelligence within rich, user-friendly experiences.

## ✨ Core Features
- **Modern Dark-Mode Aesthetic**: Engineered with sleek glassmorphism themes and tailored design tokens.
- **Fluid Micro-Animations**: Leveraging Framer Motion for scroll-reveals and seamless object transitions.
- **Intelligent Tech Showcase**: Interactive, color-coordinated grids mapping out my Frontend and AI Data stacks.
- **Responsive Architecture**: Fully responsive Single Page Application (SPA) compatible with all modern devices.

## 🛠 Tech Stack
- **Framework**: React 18 / Vite
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide-React & React-Icons
- **Deployment**: Static SPA deployed securely on GitHub Pages
